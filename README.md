##E-Wallet System – Project Overview

The E-Wallet System is a **Java-based console application** that allows users to manage their digital wallet accounts and perform basic financial transactions.

The system includes features such as Sign Up, Login, Forget Password, Deposit, Withdraw, Transfer Money, View Account Details, Change Password, and Logout.

The project is built entirely as a **console-based application**, with no graphical user interface (GUI) or web interface. It uses Object-Oriented Programming (OOP) principles and a layered architecture that separates models, services, service implementations, and global validation utilities.

The main goal of this project is to practice Java programming, OOP concepts, interfaces, exception handling, input validation, and clean code organization while building a simple digital wallet system.
